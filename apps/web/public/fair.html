How the game is kept fair

Six plain facts for every player and every organizer.

  1. Nobody picks the numbers. Not the Organizer, not the Host, not the Co-host, not an AI assistant and not the people who run the site. Each number comes from a public random value that the whole world can see.
  2. Everyone gets the same number. The public random value is published every few seconds. Every phone in the game reads the same value, so every phone shows the same number at the same time. No number is ever sent to you: every phone works it out from the same public values.
  3. Your phone checks it. Each public value carries a signature. Your phone checks the signature before it shows the number. A made-up number would fail the check.
  4. No one can know a number early. The value for each number is fixed by the game's schedule, before the value exists. Not even the site can know the next number. A pause cannot be used to look at a number and then hide it.
  5. The software decides the winners. A prize goes to a valid pattern on a card, checked against the called numbers. A result counts only when several different phones agree. No person can choose, change or remove a winner. A wrong claim simply does not count.
  6. You can see what happened. The Organizer gets a game record: every prize with its winning card. The record is kept for 365 days.
An honest limit. This makes cheating very hard, not impossible. In theory, very many people with many phones could agree on a false result. This is stated because it is true.
